열리지 않으면 아래 ‘연결 준비’를 확인해 주세요. Jupyter 비밀번호는 soda예요.

🛠️ 연결 준비

유선 연결 — Mac
  1. 랜선을 차량과 Mac(USB 랜 어댑터)에 연결해요.
  2. 시스템 설정 → 네트워크 → 랜 항목 → 세부사항 → TCP/IP로 들어가요.
  3. IPv4 구성을 ‘수동으로’로 바꾸고 IP 192.168.101.102, 서브넷 255.255.255.0을 넣어요.
유선 연결 — Windows
  1. Win+R → ncpa.cpl → 새 이더넷 우클릭 → 속성으로 들어가요.
  2. ‘인터넷 프로토콜 버전 4(TCP/IPv4)’를 더블클릭해요.
  3. IP 192.168.101.102, 서브넷 255.255.255.0을 넣고 확인을 눌러요.
차량 Wi-Fi(핫스팟) 연결
  1. 기기의 Wi-Fi 목록에서 차량 이름(hostname)으로 된 네트워크에 연결해요. 이름은 부팅할 때마다 바뀌어요.
  2. 위에서 ‘차량 Wi-Fi’를 고르고 리모컨 앱을 열어요.
앱이 꺼져 있을 때 켜는 방법
  1. Jupyter를 열고 Other → Terminal을 실행해요.
  2. ~/Project/python/notebook/autocar_app/start.sh를 입력하고 Enter를 눌러요.
  3. 끌 때는 ~/Project/python/notebook/autocar_app/stop.sh를 입력해요.

🎮 리모컨 앱 기능

  • 수동 운전 — 전진·후진·대각선, 속도 조절 (누르고 있는 동안만 움직임)
  • 자율주행 — 초음파 센서로 장애물을 피하며 주행
  • 순찰 돌기 — 사각형 경로 반복, 비상등·순찰 알림음
  • 8자 주행
  • 스피커 — 경적, 사이렌, 작은 별, 딩동 / 부저 멜로디
  • 전조등·후미등·비상등, 카메라 화면, 배터리·거리 표시
